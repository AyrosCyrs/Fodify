# Fodify

Aplicación móvil de menú digital para restaurante/cafetería, desarrollada como proyecto para la materia de Desarrollo de Dispositivos Móviles (Facultad de Ciencias, UNAM).

## ¿Qué hace la app?

Fodify permite a los clientes de un restaurante consultar el menú completo desde su celular, organizado por categorías:
- Desayunos
- Platillos principales (entradas)
- Bebidas

Cada producto se muestra con su imagen, descripción y presentación visual, simulando la experiencia de una carta de restaurante real.

## Funcionalidades principales

- **Inicio de sesión** de usuario (login funcional)
- **Navegación por categorías** de menú mediante un menú lateral (drawer)
- **Catálogo visual** de productos con imágenes para cada platillo/bebida
- Diseño pensado para una experiencia de usuario simple e intuitiva

## Tecnologías utilizadas

- **Kotlin** — lenguaje de programación
- **Android Studio** — entorno de desarrollo
- **Gradle (Kotlin DSL)** — gestor de dependencias del proyecto
- Componentes de Android: Activities, Adapters (RecyclerView) para las listas de productos

## Cómo ejecutarlo

1. Clona este repositorio
2. Ábrelo con Android Studio
3. Espera a que Gradle sincronice las dependencias
4. Ejecuta la app en un emulador o dispositivo Android
